# 2026ドラフト候補ソート page phase 8 比較画面の設計

## 実行内容

phase 8 として、`/draft-candidate-sort/sort` の比較画面を、ユーザー向けの進行状況と候補者カード中心の表示に整えた。

## 更新ファイル

- `app/draft-candidate-sort/sort/DraftCandidateSortQuestion.tsx`

## 表示内容

比較画面では以下を表示する。

- 現在の比較数
- 全比較数
- 完了率
- 完了率バー
- 左の候補カード
- 右の候補カード
- 回答ボタン

## 候補者カード

候補者カードに表示する項目は以下に限定する。

- 氏名
- 所属
- 区分
- ポジション
- 投打・身長体重

以下は表示しない。

- 評価
- 各スポーツ紙名
- 各紙の印
- 判定根拠
- 参照元
- 外部リンク
- 詳細リンク

## 回答ボタン

回答ボタンは以下。

- 左を上にする
- 右を上にする
- どちらも同じくらい
- 両方知らない
- 戻る

`どちらも同じくらい` は phase 5 の20%ルールに従い、自動で非表示になる。

`戻る` は回答が0件の場合に無効化する。

- 進行状況の完了率を計算できる

## phase 8 完了条件
