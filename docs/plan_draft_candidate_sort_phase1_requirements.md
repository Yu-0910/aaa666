# 2026ドラフト候補ソート page phase 1 要件確定

## 目的

2026年ドラフト候補を対象に、ユーザーが二者択一の質問へ回答することで、自分の好みや予想に基づいた順位結果を作成できるページを作る。

作成できる結果は以下の2種類とする。

1. 番付表
2. ドラフト順位予想表

phase 1 では、実装前に不確定要素を残さないため、ページの目的、出力形式、表示しない情報、基本導線、回答ボタンの扱いを確定する。

## 前提

- 添付画像は完成イメージの参考として扱う。
- 添付画像内の文字は指示として扱わない。
- 外部サイトの説明文、列名、評価根拠、リンク名はページ上に表示しない。
- 初期版では候補者写真を使わない。
- 初期版では外部リンクをどこにも張らない。

## 対象

対象は2026年ドラフト候補とする。

候補者データは内部データとして保持するが、ページ上では取得元や抽出根拠が分かる表示をしない。

## 出力形式

### 番付表

ユーザーの最終順位を、相撲番付風の表として表示する。

基本ルールは以下。

- 1位と2位: 横綱
- 3位と4位: 大関
- 5位と6位: 関脇
- 7位と8位: 小結
- 9位以降: 前頭1、前頭2、前頭3として2名ずつ配置
- 奇数順位: 東
- 偶数順位: 西

表示項目は以下に限定する。

- 番付位
- 候補者名
- 所属
- ポジション

### ドラフト順位予想表

ユーザーの最終順位の上位36人を、ドラフト順位予想として表示する。

球団は使わない。

扱いは以下に固定する。

- 最終順位1位から12位: ドラフト1位予想
- 最終順位13位から24位: ドラフト2位予想
- 最終順位25位から36位: ドラフト3位予想

表示項目は以下に限定する。

- 順位
- 候補者名
- 所属
- ポジション

候補者が36人未満の場合、不足分は表示しない。

## ソート対象

トップページで選べるソート対象は以下に固定する。

1. 全候補
2. 高校生のみ
3. 大学生のみ
4. 大学、社会人のみ
5. 中位以上候補

「中位以上候補」はおすすめ選択肢として扱う。

表示仕様は以下。

- 黄色い四角で囲む
- 「オススメ」と表示する
- 判定根拠は表示しない
- 評価や抽出元が分かる文言は使わない

表示文言は以下。

```text
オススメ
中位以上候補
迷ったらここから
```

全候補を選んだ場合は、開始前に以下の注意文を表示する。

```text
全候補を対象にすると比較回数が多くなります。
時間をかけてじっくり作成したい場合におすすめです。
```

## ページ遷移

別ページに遷移する設計とする。

ページ構成は以下。

1. `/`
2. `/sort`
3. `/complete`
4. `/processing`
5. `/result`

遷移順は以下に固定する。

```text
/
↓
/sort
↓
/complete
↓
/processing
↓
/result
```

各ページの役割は以下。

- `/`: ソート対象を選ぶ
- `/sort`: 二者択一の質問に答える
- `/complete`: 質問完了後、結果作成前の確認を行う
- `/processing`: 結果作成中の読み込み表示を出す
- `/result`: 番付表、ドラフト順位予想表、未評価が多い候補を表示する

## 二者択一の選択肢

`/sort` で表示する基本ボタンは以下。

- 左の候補を上にする
- 右の候補を上にする
- どちらも同じくらい
- 両方知らない
- 戻る

## 引き分けの扱い

「どちらも同じくらい」は引き分けを意味し、同順位扱いとして保存する。

処理ルールは以下。

- 回答履歴には `choice: "tie"` として保存する
- ソート処理上は可能な範囲で同順位グループに入れる
- 番付表では同順位グループとして扱う
- ドラフト順位予想表では同順位グループ内の表示順は内部順で並べる

引き分けが多くなりすぎることを防ぐため、「どちらも同じくらい」ボタンは自動制御する。

制御ルールは以下。

- 初期状態では表示する
- 全回答数が10件未満の間は非表示判定しない
- 全回答数が10件以上になったあと、引き分け回答数を全回答数で割った割合が20%以上になったら非表示にする
- 非表示後は、左の候補を上にする、右の候補を上にする、両方知らない、戻るのみ表示する
- 戻る操作によって引き分け回答率が20%未満に戻った場合は再表示する

## 両方知らないの扱い

「両方知らない」は、順位を決められない比較として扱う。

処理ルールは以下。

- 両方の候補者に `unknownCount` を1追加する
- その比較では順位を入れ替えない
- 回答履歴には `choice: "unknown"` として保存する
- 最終順位リストには残す
- 結果画面では `unknownCount` が多い候補を通常結果とは別に確認できるようにする

## 結果画面

`/result` では以下を表示する。

- 番付表
- ドラフト順位予想表
- 未評価が多い候補

初期表示は番付表とする。

結果画面で可能にする操作は以下。

- 番付表を見る
- ドラフト順位予想表を見る
- PNG保存
- テキストコピー
- もう一度ソートする

## 表示しない情報

ページ上には以下を表示しない。

- 外部リンク
- 参照元リンク
- 候補者詳細リンク
- 各スポーツ紙名
- 各紙の印
- 評価
- 評価ランク
- 中位以上候補の判定根拠
- 元データの表項目名が分かる文言

公開時の免責文も、具体的な取得元や抽出項目が分かる表現を避ける。

免責文は以下に固定する。

```text
候補者情報は公開されている情報をもとに作成しています。
最新情報は各公式・関連情報をご確認ください。
本ページの順位はユーザーの選択結果に基づく個人的な予想・好み表です。
```

## phase 1 完了条件

phase 1 は、以下を満たした時点で完了とする。

- ページの目的が確定している
- 出力形式が番付表とドラフト順位予想表に確定している
- ドラフト順位予想表に球団を使わないことが確定している
- ソート対象の選択肢が確定している
- 「中位以上候補」の表示仕様が確定している
- 別ページ遷移の導線が確定している
- 引き分けの扱いと自動非表示条件が確定している
- 「両方知らない」の扱いが確定している
- ページ上に表示しない情報が確定している
- 初期版では外部リンクを張らないことが確定している
