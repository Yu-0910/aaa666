## 参照定義の出典（定義テンプレはここに準拠して記入済み）

本リポジトリの投球指標テーブル見出しは、**プロ野球 ヌルデータ置き場 f3（nf3）**の「投手成績・Advanced」系の列名と一致する。公開ヘルプに **式と日本語説明**があるため、下表の **参照元** は原則として次を用いた。

- **参照 URL**: [ヘルプファイル - 投手成績 -](https://nf3.sakura.ne.jp/Help/Help_pc.htm)（同一サイト内「ヘルプファイル - 各種成績(投手) -」も補助）

**注意（必読）**

1. **NPB 公式の正式定義ではない**。Wikipedia 等でいう「援護率（Run Support）」は **(降板前の味方得点×9)÷攻撃回数** 等と説明されることが多く、**nf3 の「援護率」は「援護点・援護回」ベース**で細則が異なる。
2. **実装前にプロダクト判断**: 「nf3 に揃える」「Wikipedia 型に揃える」「NPB.jp / スポーツナビの表示に寄せる」のいずれかを決め、決めた出典だけを `参照元` に残す。
3. 見出し列 **KD** は nf3 独自の「貢献度」インデックスだったため **UI から削除済み**。

**フェーズ 0 の残タスク**: 下表は **文献上の定義を埋めた状態**。プロダクトで採用する行を確定し、必要なら式を差し替えてから実装する。

## 列別実装方針

### 2 段目

#### 援護率

- **必要データ**: 投手の **登板区間** における **自チームの得点**（イニング別得点が理想）。
- **手順**: `game.scoreboard` 等からイニングスコアを正規化し、`pitchingLines` 由来の **表・回・先発/救援** と突合。率の式（例: 9 イニング換算・登板あたり平均）はフェーズ 0 で固定。
- **出力**: `player_season_pitching_poc` の `basic` または `metrics` ブロックに数値フィールドを追加し、UI は表示のみ。

#### IPR

- **前提**: フェーズ 0 で式が確定してから着手。
- **手順**: 援護・失点・回数のどれと合成するか定義に従い、同一パイプライン（`phase_pitcher_poc1` または後続スクリプト）で算出。

#### NHB%

- **前提**: フェーズ 0 で定義確定。
- **手順**: canonical 上の **勝敗・ホールド・セーブ** 等から再現可能か検証。再現不能なら **明示的にスコープ外** とし、取得ソースを別途検討。

#### LOB%

- **必要データ**: 打席単位の **出塁** と **イニング内の得点/残塁**（残塁追跡）。
- **手順（いずれか）**: (A) `paSituationSim` 等のシミュレーション拡張、(B) 細粒度スコアボードの取り込み。`docs/yahoo_npb_game_data_integration_plan.md` の Phase 11 と同趣旨。
- **式**: サイト定義に合わせ **LOB% = 残塁 / 相手出塁** 等を固定（一般的定義は複数あるため要確認）。

#### RSAA

- **必要データ**: **リーグ平均** または **期待失点**（イニング・状況別モデル可）。
- **手順**: `_data/derived/` またはマスタに **年・リーグ係数** を置き、**年次バッチ**で更新。個人ページ JSON には **係数適用後の値** だけ載せる。

#### RSWIN

- **前提**: フェーズ 0 で定義確定。
- **手順**: 定義が「特定条件の勝ち数」なら、勝敗・先発/救援・スコアから機械化できるか検証。

### 3 段目

#### PR

- **前提**: フェーズ 0 で式確定後、リーグ平均防御率と個人防御率をマスタから供給できるか確認して実装。

#### 援護回・援護点

- **必要データ**: 援護率と同じ **イニング得点 × 投手登板区間**。
- **手順**: 「援護回」= 得点が発生したイニング数、「援護点」= 合計得点など、**用語をドキュメントで固定**してから実装。

#### 救援時回数・救援時失点

- **必要データ**: **救援** に限定した投球イニング（または登板）と **失点**。
- **手順**: 既存の先発/救援判定（`phase_pitcher_poc1` の PoC 近似）を利用し、救援のみフィルタ。定義を公式に寄せる場合はスタメン・継投メタの精度を別タスクで上げる。

## 定義テンプレ（nf3 ヘルプに基づき記入済み・採用時は要レビュー）

変数の意味: **IP**＝投球回（イニング）、**R**＝失点、**ER**＝自責点、**W 勝 / H ホールド / S セーブ** 等。リーグ値は **同一リーグ・同一年度** の集計が前提。

| 列名 | 参照元 | 式 | 丸め | 備考 |
|------|--------|-----|------|------|
| **援護率** | nf3 ヘルプ「援護率」 | **援護率 = (援護点 × 9) ÷ 降板までの援護回**（先発のみ対象の説明）。**援護点**＝先発登板中に味方が取った得点の合計。**援護回**＝先攻/後攻・回の途中/終了で **降板までの「援護を数える回」の数え方**が細則あり（ヘルプ本文の「援護回の割り出し方」参照）。 | 小数第 2 位など UI 統一で可 | Wikipedia 系の (味方得点×9)÷攻撃回数 とは **分母の取り方が異なる**可能性 |
| **IPR** | nf3「IPR」 | **IPR = (救援時の投球回) ÷ (救援時の失点)**。英名: Inning Per Runs（1 失点あたり何イニング投げたかの逆数イメージ）。**救援時の失点が 0** のときは不定のため **便宜上 99.00**（nf3）。 | 小数第 2 位 | **救援**のみ。先発のみの投手は対象外または「—」扱い要検討 |
| **NHB%** | nf3「NHB%」 | **NHB% = NHB ÷ 救援登板数**。**NHB**＝救援登板のうち **安打・与四死球をいずれも許さなかった**登板回数（出塁を許さない＝**失策出塁は投手責任とみなさずカウントしない**との説明）。 | 小数第 1 位 + `%` 等 | 分母は **救援登板数**（規定救援登板数フィルタは nf3 ランキング用） |
| **LOB%** | nf3「LOB%」 | **LOB% = (安打 + 四球 + 死球 − 失点) ÷ (安打 + 四球 + 死球 − 1.4 × 本塁打)**。Left On-Base percentage（出塁させた走者の残塁率）。 | 小数第 1 位 + `%` 等 | 分母が 0 や負になるケースの扱いは実装時にガード必須 |
| **RSAA** | nf3「RSAA」 | **RSAA = [(リーグ平均失点率 − 個人の失点率) × 投球イニング] ÷ 9**。Runs Saved Above Average。 | 小数第 2 位など | **リーグ平均失点率**は年次マスタまたはバッチ算出が必要 |
| **RSWIN** | nf3「RSWIN」「RPW」 | まず **RPW = 10 × √[(リーグ得点 + リーグ失点) ÷ リーグ投球回]**（Runs Per Win）。次に **RSWIN = RSAA ÷ RPW**。 | 小数第 2 位など | RSAA・リーグ集計と同じ前提 |
| **PR** | nf3「PR」 | **PR = [(リーグ平均防御率 − 個人の防御率) × 投球イニング] ÷ 9**。Pitching Runs（**RSAA の自責点版**との説明）。 | 小数第 2 位など | 防御率は通常 **自責点ベース** |
| **援護回** | nf3「援護回」 | **先発登板に打線の援護を受けた回数**（援護率の「援護回」と同じ概念）。 | 整数 | イニング別スコアと降板タイミングが必要 |
| **援護点** | nf3「援護点」 | **先発登板時の援護点数**（味方得点の合計・降板前まで等は援護率の細則に従う）。 | 整数 | 同上 |
| **救援時回数** | nf3「救援時回数」 | **救援登板時の投球回数**（救援に限定した IP）。 | 回数表記 | 先発/救援の判定と一致させる |
| **救援時失点** | （nf3 サンプル表に列あり・ヘルプ1表目は「救援時回数」まで） | **救援登板に限った失点**の合計と解釈するのが自然（公式 BIS 系でも救援別集計あり）。式の明示は **出典ページの追補または nf3 実データ検証**推奨。 | 整数 | IPR の分子と整合させる |
| **NHB** | nf3「NHB%」 | **NHB% の分子**に相当する **回数（達成した救援登板数）**。**NHB** 単独列は **回数**、**NHB%** は **NHB ÷ 救援登板数**。 | 整数 | 2 段目 NHB% と 3 段目 NHB は **同じカウント体系** |
