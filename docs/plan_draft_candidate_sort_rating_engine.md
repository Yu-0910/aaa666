# 2026ドラフト候補ソート レーティング方式

## 実行内容

設問数削減のため、二者択一の出題方式をレーティング方式へ変更した。

## 実装内容

- 候補者ごとに `rating` を持つ
- 候補者ごとに `comparisonCount` を持つ
- 候補者ごとに `confidence` を持つ
- 勝敗または引き分けで Elo 風に rating を更新する
- `両方知らない` は rating を変えず、比較回数と未評価回数だけを更新する
- 次の出題は rating が近い候補、比較回数が少ない候補、上位36人周辺を優先する
- 上位36人が安定した場合、または最大設問数に達した場合に完了する

## 最大設問数

2026-09-17 時点の候補者データでは以下。

- 中位以上候補: 94人 → 最大80問
- 高校生のみ: 78人 → 最大67問
- 大学生のみ: 77人 → 最大66問
- 大学、社会人のみ: 160人 → 最大110問
- 全候補: 238人 → 最大110問

## 完了条件

以下のいずれかで質問完了とする。

- 候補者が1人以下
- 上位36人が安定した
- 最大設問数に達した
